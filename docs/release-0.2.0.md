The Samsung Legacy package can now offer its built-in PLAYER engine alongside HTML video. Down opens playback controls; arrows and OK select the native option or browser fallback. The bridge implements timing, pause/resume, seeking, completion and failures, and the About screen can query read-only firmware/system versions through NNavi.

This is an experimental app release. Native installation, PLAYER execution and NNavi queries have not succeeded on the research TV. No replacement operating system, newer browser/DRM engine or subscription-service integration is supplied. Paramount+ and the requirement for all modern streaming services remain unimplemented and unverified.

Validation: JavaScript state/native-contract tests and ES5 parsing passed; all 12 Python test methods passed; repeated native/portable builds produced identical hashes. Desktop Chromium played the real bundled clip through ten seconds, and a visibly labeled simulation exercised remote control, native failure and browser recovery. These desktop checks are not hardware acceptance. See [verification](https://github.com/Coding-Dev-Tools/legacy-tv-hub/blob/main/docs/verification.md#preview-02-native-player-development) and the attached `release.json` for archive hashes.

The native ZIP is a Samsung 2014 Legacy user widget, not a firmware file, Tizen WGT or Android APK. An installed app bundles its code and demo; ongoing video sources must be independently available. The temporary installation PC is not a permanent streaming dependency. See [installation and removal](https://github.com/Coding-Dev-Tools/legacy-tv-hub/blob/main/docs/samsung-legacy.md).
