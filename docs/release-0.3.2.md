# Preview 0.3.2 — October 22, 2026

Refresh the browser app home screen into a clearer media hub with remote-friendly sections for direct video, the local library, recent playback, the bundled demo and TV/app compatibility.

The interface now states that it runs in the existing TV browser and does not replace Smart Hub, update firmware or provide Paramount+ and other protected streaming apps. Compatibility details distinguish the tested H.264/AAC demo from unverified media formats and state that AppCache survival across a TV power cycle remains unverified.

This release adds no new player, firmware, operating system, DRM, service integration, external API or account-data collection. Preview 0.3.2 automated browser coverage must not be confused with physical-TV validation: the previous preview 0.3.1 passed the measured cached reopen and demo playback on the UN55HU7250; the new visual treatment and cold-boot persistence still require verification on that TV.
